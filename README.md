# ADTU SWAYAM Engineering Psychology Quiz Portal

An online assessment and self-test portal for Assam Down Town University students based on the SWAYAM NPTEL Engineering Psychology curriculum (IIT Guwahati).

## Features
- **Curriculum-Aligned**: Includes all 80 questions across Weeks 1 to 8 with comprehensive explanations from the official course materials.
- **Strict Anti-Cheat Proctoring**: Fullscreen mode enforcement and tab-switch monitoring (maximum 2 tab switches before auto-submission and disqualification).
- **Randomized Question Bank**: Shuffles questions uniquely per student enrollment number.
- **Instant Detailed Review**: Comprehensive scorecard and breakdown of mistakes with official explanations.
- **Clean Minimalist Design**: Modern and responsive UI styled with Tailwind CSS.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Database**: MongoDB Atlas with Mongoose
- **Styling**: Tailwind CSS & Lucide Icons
